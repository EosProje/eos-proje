# EOS Proje - Lazer Tarama ve BIM Modelleme

Profesyonel 3D lazer tarama, BIM modelleme ve dijital dokümantasyon hizmetleri sunan EOS Proje'nin kurumsal web sitesi.

## 🚀 Özellikler

- ✅ **197 sayfa** (95 TR + 95 EN + 7 teknik)
- ✅ **78 dinamik lokasyon sayfası** (39 coğrafi hedef × 2 dil)
- ✅ **SEO optimize** (Canonical, Sitemap, JSON-LD Schema)
- ✅ **Çok dilli destek** (Türkçe/İngilizce)
- ✅ **Modern UI/UX** (Tailwind CSS)
- ✅ **Responsive tasarım**
- ✅ **Next.js 14** (App Router)

## 📦 Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Development server
npm run dev

# Production build
npm run build

# Production server
npm start
```

## 🌐 Deployment

Bu proje Vercel üzerinde deploy edilmek üzere optimize edilmiştir.

1. GitHub'a push yapın
2. Vercel otomatik olarak deploy eder
3. https://www.eosproje.com adresinde yayınlanır
